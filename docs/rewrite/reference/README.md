# Visual reference

The approved low-poly homepage visualization from the design conversation is the composition reference. The repository specification records the geometry/camera numerically so implementation does not depend on tracing a raster image.

Use it for room proportions, camera composition, placement of the map/table/radio desk/telephones/projector, low-poly fidelity, and hanging-board placement.

Critical board rule:

> The board is approximately one row high and displays only the currently selected area name.

It must not become a multi-row navigation list. The implementation remains original and should not reproduce game branding, copyrighted text, or exact proprietary assets.
